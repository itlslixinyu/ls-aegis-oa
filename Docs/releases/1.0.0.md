# 1.0.0

## 功能范围

统一身份认证、角色与数据权限，提供进销存、报价、运维报修和电子签章。管理端、客户H5、工程师H5共用平台后端；Android目录提供WebView测试工程。代码生成和应用管理不在产品范围内。

## 运行要求

后端使用JDK 21；PC使用pnpm 9，H5使用npm及对应锁文件。构建和部署入口见[开发指南](../guides/development.md)和[部署指南](../operations/deployment.md)。

## 升级与限制

- 由旧项目建立独立源码维护基线，源码版本更新不会自动替换已部署服务。
- 全新数据库使用init.sql；已有数据库必须按适用范围执行增量升级，禁止重放全量初始化。
- Android测试工程不代表完整原生客户端；真机硬件、外部地图与证书信任链、容量指标需在目标环境单独验收。
