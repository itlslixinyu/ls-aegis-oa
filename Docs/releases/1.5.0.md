# LS·Aegis 雷铄 OA 安全应用构建平台 1.5.0

客户服务 App 支持同一公司内每人使用独立账号。普通员工仅能查看自己提交的报修及关联工单和附件，并确认自己的维修结果。公司管理员可查看和确认本公司全部报修。

在平台“进销存 → 往来单位 → App成员”签发新增成员码或指定账号的密码重置码，也可维护成员角色和启停状态。成员在 App 的“首次使用”入口激活账号。升级后原账号保留密码并作为公司管理员，重新登录后即可使用。历史报修缺少提交人时，仅对公司管理员开放。

已有数据库执行新增的 Liquibase 迁移。使用手动数据库升级流程的部署应执行同一迁移文件中的变更。全新部署使用 `ls-aegis-server/sql/init.sql`；已有库保留业务数据和卷。该平台版本可由现有 App 加载。
