# LS·Aegis 雷铄 OA 安全应用构建平台 1.2.0

## 报修与工单池

客户提交报修即保留记录。提交满十分钟仍无人实际接单的报修进入同租户工程师工单池，不要求后台先确认或手动转单。工程师领取时自动衔接维修工单；同一报修仅一人领取成功，重复请求不重复建单。工单池只公开故障摘要，联系人及附件继续受任务权限约束。

新派单仅指定工程师，工程师确认接单后进入待开工；存量已接单任务保持原状态。后台取消、派单和领取均校验当前状态，避免覆盖已完成的领取。

## 维修记录

维修记录按处理情况、使用配件、照片顺序填写，新增页面从顶部进入。配件从现有商品与仓库档案选择，数量和备注与维修记录一起保存；失败整体回滚。工程师不填写价格，价格参考来自商品档案，后台结算仍须核对收费，实际库存成本由PSI结算出库核算。

工程师端将维修完成与财务结算分开呈现，完成按钮在记录及配件之后；签退后显示维修已完成，后台工单仍为待结算。报修地址与签到、签退地址分别保存和显示，不再单列旧维修地址。

## 图片与账号流程

两端App统一原生拍照、相册选择和按需权限处理，图片支持校验、排队、失败重试、预览及离页释放；PC图片入口同步沿用统一文件组件。照片定位不可用时保留时间水印，签到和签退仍要求有效坐标。

水印按报修、维修和完成阶段区分资料标题，分别展示客户、人员、地址及备注，长文字换行后调整水印区域。Android优先使用系统地址解析，失败回退坐标，平台外部地图调用保持停用。

工程师端补齐修改密码页面和过期引导，继续使用平台SM2传输加密、密码策略和会话隔离；H5生产及开发代理覆盖个人改密PATCH接口，避免请求落入静态页面。

两端App支持构建时配置HTTPS入口；可选Compose移动网关复用现有服务，局域网交付不依赖ADB端口转发。调试CA仅信任指定服务器，正式发布使用系统可信证书，密钥及环境配置独立管理。

## 客户入口与升级

旧报修列表链接和提交后跳转统一到现行页面；列表继续分页，切换筛选丢弃旧请求结果。Android使用系统定位与地址解析，平台外部地图调用保持停用。

平台与客户服务、工程师App同步为1.2.0，Android安装码8。升级新增可空的报修地址字段及工单池查询索引，不回填存量地址，不清理业务数据。Liquibase启用时执行登记的新迁移；本机关闭Liquibase的Compose环境须先执行专用增量升级脚本，再切换应用。
