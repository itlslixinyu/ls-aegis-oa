# 图片上传流程

先读当前仓库根AGENTS，再执行[工作流与验收](references/workflow.md)。项目角色位于工作区`agents/image-upload/AGENTS.md`；本Skill安装到个人目录后仍以当前工作区为操作范围。

- 沿真实调用链盘点，覆盖H5、PC和Android；复用平台文件中心和既有角色身份，不以按钮隐藏代替服务端归属检查。
- 拍照、相册和取消必须作为独立来源流程验收；原生层处理系统能力，网页复用队列。读[来源与权限](references/source-permissions.md)，不以相册回传代替拍照验收，不以权限开启代替设备可用。
- 已选照片不得静默丢弃：上传中禁止提交，失败必须显式重试或删除后再提交。超时不自动重复业务写入；上传重试和单据提交分开设计。
- 文件格式、大小、解码边界以各入口契约为准；报修至少1张最多9张，工程师两组各最多6张，保留现有必填语义。不把文件改后缀当格式转换。
- 拒绝定位后允许时间水印，不能伪造坐标。完整照片、Token、真实地址及原生权限信息不进入公开报告。
- 保留已关联附件，删除及离页只释放本页拥有的预览资源。服务器未关联文件按经过授权、可追踪的规则清理，禁止按整个目录或年龄盲删。
- 每批执行适用构建、算法/状态测试、浏览器或原生检查、后端关联闭环，保留层级证据。环境受阻时继续独立项目并记录未完成项，不能声称全流程通过。
