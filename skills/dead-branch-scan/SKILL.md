# 固定分支扫描

读根 `AGENTS.md` 和 `agents/code-cleanup/AGENTS.md`。输入Java/TS/Vue源码、现有分析结果及运行号。

使用可用静态分析器或编译器AST找候选，记录条件表达式、绑定/作用域、赋值点及规则ID；字符串搜索只作定位。枚举默认分支、输入校验、异常兜底和防御性空判不因某次运行未走到而算死分支。

LOW需证明条件在全部受支持环境固定，条件求值无副作用，被移除分支不含资源/异常/初始化或外部消费契约。简化须保留求值顺序、作用域和控制流；不能把有副作用的条件直接删掉。

配置文件、数据库字典、权限/角色、租户、运维可切开关、灰度、feature flag、import.meta.env/构建mode以及条件装配均只标记；不因为当前部署禁用就当永远false。历史功能可能恢复时列人工复核，conservative不通过注释掉代码来“保留”。命中基座/国密/GB28181/任务/队列/外部API时PROHIBITED_AUTO。

输出 `dead-branches.csv`，附常量取值证明、全部赋值来源、控制流影响与候选diff。阶段5仅执行被证据批准的LOW白名单，禁止清除配置驱动或权限分支。
