# 分阶段验收矩阵

阶段0：确认目标、版本/构建标识、用户角色与测试资料、现状快照、补偿路径、监控和停止条件。默认并发1；并发幂等用例仅同一合成记录双请求。未确定真实性能目标时仅记录测量，不做性能通过结论。

## 模块顺序

| 顺序 | 模块/能力 | 必测内容与依赖 |
|---|---|---|
| 01 | 平台底座与部署 | boot/common/starter/mybatis/redis/crypto：分层/依赖、环境隔离、国密、连接与只读健康；数据库变更脚本、日志脱敏、监控/回退 |
| 02 | 认证、用户与RBAC | security/rbac：登录/退出、菜单与接口一致，拒绝请求后的身份隔离；租户/部门/本人访问边界 |
| 03 | 租户管理 | biz-tenant：启用状态与隔离；未启用部署记不适用并说明，不伪造通过 |
| 04 | 文件 | biz-file：上传/预览/下载、类型大小、越权/引用、失败重试；清理仅合成未引用文件 |
| 05 | 消息公告 | biz-notice：草稿/发布范围、已读、越权；只用测试接收人，无真实广播 |
| 06 | 已移除范围核对 | 代码生成、应用管理及已不存在的biz-open不再生成待测功能；以当前Controller/路由/POM核对已移除状态。系统登录客户端配置归认证阶段02，不恢复旧应用凭据管理 |
| 07 | 调度 | biz-schedule：任务状态、异常/重试/幂等；只用无外部副作用任务，不运行任意生产脚本 |
| 08 | 基础资料与进销存 | biz-psi：客户/供应商/分类/商品/仓库→采购→库存→销售→应收应付→核销→汇总；FIFO、税额、缺货回滚、并发重试和冲销 |
| 09 | 报价 | biz-quote：独立报价状态/金额/终态限制、商品回显、DOCX/PDF；兼容转工单另列，不强制耦合 |
| 10 | 运维维修与财务 | biz-eoms：报修/派单/工程师/结算/应收/实收；经PSI维修出库，确认不记实收；客户和工程师权限 |
| 11 | 签章 | biz-sign：合成文件/测试印章证书、授权/普通与合并签章/回执/篡改拒绝/幂等；没有安全测试证书则写操作BLOCKED |
| 12 | PC、客户H5、工程师H5 | 三端按角色完成对应模块流程；类型、组件、请求乱序、权限、异常反馈、加载、设备适配与刷新回显 |

父reactor与16个子模块共17个项目均按当前POM归属；监控、系统配置、字典/菜单按实际路由归入平台/RBAC阶段。代码生成和应用管理已移除，不再测试预览/下载或恢复旧接口。工作台聚合展示在各来源模块后再验收；静态组织检查可提前，不代表功能验收已通过。

## 各模块共用检查

| 维度 | 验收与证据 |
|---|---|
| 工程与配置 | 职责层次、无循环依赖/平行底座；环境配置、密钥不入库；冗余依赖先查调用再移除；部署可复现 |
| 后端 | Controller/Service/Mapper职责，统一R/异常码，参数与空值/边界，事务/CAS/幂等，SQL分页/索引/批量/权限、外部超时/有限重试/补偿 |
| 前端 | Arco PC/Vant H5、组件边界/类型门禁、字符串ID、请求取消/版本、菜单及接口权限、上传预览和错误/空态 |
| 数据与并发 | 表/索引/约束/精度/逻辑删除、迁移脚本，库存和应收实收口径，重复提交/乱序/CAS/事务回滚；不在在用实例执行DDL回退演练 |
| 维护与部署 | 清理调试输出/占位随机数据但保留必要审计；减少重复逻辑，日志追踪/脱敏、健康/告警、资源与备份回退能力 |
| 清理 | 精确ID+运行号核对、依赖逆序撤销/冲销、净库存与余额恢复，附件/缓存/待办回查，审计留痕；残留与真实引用明确登记 |

上述编码要求为项目规范，不能全部冒充国家标准原文要求。每项附需求ID、预期、实际、证据与重测记录。

## 模块退出与联合测试

每模块适用的必测用例全部PASS；无未关闭的影响业务正确性、安全、金额/库存或清理的缺陷；其他缺陷有明确处置；清理回查通过。BLOCKED/NOT_RUN 不算PASS。N/A须有部署配置或职责边界证据并从必测集合排除；底座无独立页面时通过实际调用方验收。版本变化时根据调用链重测影响模块，保留未受影响证据的适用性判断。

所有模块退出后，创建一套新的合成资料进行联合测试：

1. 客户/商品/仓库→报价→（兼容场景）工单→维修结算→PSI维修出库→应收→实际收款→工作台。
2. 采购→库存→合同销售→FIFO成本→应收应付→收付款/核销→汇总及冲销。
3. 平台文件→项目/印章授权→签章→回执/验证/下载→附件引用处置。
4. PC派单与管理→客户H5报修/确认→工程师H5维修→PC结算/关闭；账号切换与越权拒绝。

跨域重试/部分失败、同一客户与商品ID、金额数量、会话与授权、异步通知边界、日志追踪和清理后净增量均需断言。联合结果不得从各模块PASS直接推导。
