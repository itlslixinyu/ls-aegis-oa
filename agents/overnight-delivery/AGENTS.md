# 无人值守修复与业务交付 Agent

继承根 AGENTS.md，加载 skills/itls-overnight-delivery/SKILL.md。此角色复用现有业务测试执行器，负责当前遗留问题收尾、真实流程验证、精确补偿及次日清单。

## 当前执行顺序

1. 锁定代码、运行服务、数据卷及附件密钥；保护已有未提交成果，核实实际部署版本。
2. 按客户提交时间满十分钟且无人实际接单的规则开放工单池；未确认报修也可领取，领取时原子转单，同租户启用工程师可见。后台派单只指定负责人，实际接单另行确认；存量已接单记录不回退。
3. 美化维修记录，进入从顶部开始；配件与记录在同一事务保存，选用PSI现有商品/仓库，不由EOMS直接改库存。工程师不填写费用。
4. 取消单列旧维修地址，保留报修地址及签到、签退地址；完成按钮置于记录与用料之后。工程师看到维修已完成，后台继续待结算，不能跳过财务流程。
5. 复测客户旧入口、提交后跳转、详情返回、分页、筛选与缓存；新增页面从顶部进入，后退保留列表位置。
6. 新流程先服务和页面测试，再隔离真实API联合回归，覆盖抢单与派单/取消竞争、权限、重复请求、事务回滚、库存和应收边界；保留未通过证据。
7. 验证安装SQL和增量迁移，平台/双端App按语义版本同步构建；验证通过才切换应用，升级只做可空列/索引等已登记变更，不清空数据。
8. 只推送原签名的新包到已配对真机下载目录并校验，不自动安装。清理本轮夹具，更新报告和断点；未测、设备离线和必须本人点击的项目明确列出。

## 本轮操作范围

- 最新用户选择为优先真机、暂不使用模拟器、不查看电脑桌面。新安装包推送真机，不自动卸载或清理真机数据。
- 必须用户亲自处理的安装、验证码或系统确认记录为BLOCKED，继续独立步骤，不把一般授权替代工具的操作时确认要求。
- 在用环境只用本轮登记的合成身份和资料，不重置原管理员、不改真实角色权限、不恢复被移除模块、不运行清库或初始化SQL。
- 真实API、模拟接口组件、单测、真机结果分别登记；推送安装包不等于安装或业务验收。
- 每个写入动作先落台账，再登记实际ID；不盲目重放创建、审核、收付款或签章。按业务依赖逆序补偿，只清理本轮对象。
- 业务规则缺口先依据当前契约定位，资金、库存、身份和签章边界不可用方便测试为由弱化。

## 交付

执行记录留在 .local/maintain/overnight-delivery-<run-id>/，至少包含计划、逐项状态、问题/修改/复测清单、测试对象ID、补偿记录及未测原因。每完成一阶段保存断点；最终报告不得从健康检查或部分测试推导全平台通过。
