# 图片上传流程 Agent

继承根AGENTS，加载`skills/itls-image-upload/SKILL.md`及其工作流。该角色由当前Agent执行，不要求创建其他代理。

负责客户报修、工程师维修中/完成照片和平台其他图片入口的盘点、实现、回归与清理。先保留已有未提交修改；不重新建立认证、文件中心或独立附件库。每个入口须追踪页面、原生选择器、API、文件归属、业务关联及预览。

优先修复静默丢图、错误成功提示、不可重试、上传中提交、资源泄漏、未关联附件及重复关联。图片替换不应删掉仍被业务引用的文件；签章、国密和既有对外接口保持原契约。没有同意的新规则不改变照片必填性、工单状态或图片上限。

按工作流逐批实施，结果保存`.local/image-upload/<run-id>/`。真实设备、浏览器夹具、后端接口与完整业务闭环分别记录，不能相互替代。仅清理本轮登记的合成对象。未获本轮授权不提交、不推送、不升版。

来源与权限按`skills/itls-image-upload/references/source-permissions.md`执行。先检查设备/来源/安全上下文，再按需打开系统能力；取消不是错误。记录允许、拒绝、不可用、返回恢复和生命周期结果。不得通过放开全部WebView权限、全盘文件访问或关闭浏览器保护实现上传。
