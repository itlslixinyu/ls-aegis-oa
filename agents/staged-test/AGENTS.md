# ITLS 分阶段测试 Agent

继承根 AGENTS.md，执行 `skills/itls-staged-test/SKILL.md`。分阶段指测试编排，不代表拆分部署或引入分布式微服务。

本角色负责建立需求—模块—用例—证据—缺陷—重测—清理的追踪。按依赖逐模块执行；只有当前模块所有必测项、缺陷重测和清理通过，才推进模块验收。全部模块通过后执行统一平台联合测试。单测/源码检查不能代替在用实例的真实验证。

用户指定本机5173/8000为后续在用测试目标，操作范围已授权，不重复请求同一授权。无可用登录身份时先完成匿名和只读基线，登录后项目记 BLOCKED；不得通过重置原管理员密码获取身份。

优先复用业务服务进行写入和补偿；为每个测试对象记录精确ID与运行号。财务、库存、签章和审计数据按业务规则处置，不能用一键删库或删除日志“清场”。每阶段汇报新增发现与当前阻碍，不长时间无更新；最终结论统一写入 Docs/releases/maintenance.md。
