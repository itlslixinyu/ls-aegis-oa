# 列表表格实现

管理端统一使用Arco和现有Gi/Base组件链。布局规则见[前端表格规范](前端表格规范.mdc)，本页只说明源码职责。

| 源码 | 职责 |
|---|---|
| [BaseTable](../ls-aegis-web/src/components/BaseTable/index.vue) | 包装GiTable，归一化列和滚动配置，透传属性与插槽 |
| [tableHelper](../ls-aegis-web/src/utils/tableHelper.ts) | normalizeTableColumns、sumTableColumnsWidth、mergeTableScroll |
| [TableCol](../ls-aegis-web/src/constant/table-col.ts) | 公共列宽档位 |

标准列表沿用GiPageLayout → BaseTable → useTable。业务列优先使用公共档位；领域特有列可由领域常量维护。最终列宽和横向滚动使用既有工具计算，不在页面复制另一套测宽算法。

编号和操作列按语义配置不换行；名称列使用省略和提示。BaseTable将归一化配置交给GiTable，列设置、分页和工具栏继续复用底层能力。调整列宽、权限列或插槽时同时检查窄屏横滚、列设置缓存和操作按钮可用性。
